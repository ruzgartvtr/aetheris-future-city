# AETHERIS — My Future City

Cinematic presentation for the Grade 6 English performance: **My Future City – A Better Place to Live!**

## Files

| File | Use |
|------|-----|
| `index.html` | Fullscreen cinematic deck (open in Chrome → press **F** for fullscreen) |
| `Aetheris_Future_City.pptx` | PowerPoint for class (8 slides) |
| `description.txt` | 120–150 word written description |

Also copied to: `~/Downloads/Aetheris_Future_City.pptx`

## Present

- **HTML:** Arrow keys / click / scroll. Left third of screen = previous slide.
- **PowerPoint:** Standard slide show (`F5`).

## City content

- **Name:** Aetheris  
- **Location:** Aegean coast, near İzmir  
- **Places:** Helix Academy, Vitalis Hospital, Canopy Park, Obsidian Library, Apex Arena, Chronos Museum  
- **Ideas:** Silent Corridor (green transport), Tide & Solar Grid (clean energy), Living Towers (smart buildings)
